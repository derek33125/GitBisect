01 / Policy changes

What each variant changes

The fixed-k12 matrix launches every arm from a clean archive root, cache namespace, observations file, and run history. Historical k3 cells are displayed as prior evidence, not resumed work.

Evidence-guided diverse frontier

Preserves a semantic leader, an information-gain probe, and an issue-relevant component not represented by the leader.

k3
Not run historically.
k12
Uses the diverse causal frontier.

Structured causal parent-diff reasoning

Retrieves issue-matched parent-diff hunks and local function context before extracting symbols, mechanisms, causal linkage, confidence, and build risk.

k3
Historical causal extraction run.
k12
Same extraction at a fixed 12-candidate frontier.

Observation-conditioned posterior

Good and bad runner verdicts update the priority of unresolved candidates sharing the selected commit's extracted mechanisms and components.

k3
Historical posterior policy.
k12
Same posterior update with generic extraction.

Confidence-adaptive frontier

Uses the model and heuristic agreement signal to choose either the semantic top group or a deliberately mixed information-gain frontier.

k3
Historical confidence-conditioned policy.
k12
Same policy with a fixed 12-candidate frontier.
